    T3Client¶

    T3Client is what connect() returns. Most scripts never build one directly. See the collections, writes and reports guides for worked examples.

    T3Client ¶

    T3Client(*, auth: Auth | None = None, base_url: str = DEFAULT_HOST, license: str | None = None, profile: Profile | None = None, spec: SpecMode = 'auto', rate_limit: float | None = 10.0, concurrency: int = 10, timeout: float = DEFAULT_TIMEOUT, log_http: bool = False, transport: BaseTransport | None = None, verify: bool | str = True, proxy: str | None = None)

    A configured connection to the T3 API.

    Usually made by t3api_utils.connect. Use it as a context manager, or call close, to release its connection pool.

    base_url instance-attribute ¶

    base_url = base_url.rstrip('/')

    license instance-attribute ¶

    license = license

    profile instance-attribute ¶

    profile = profile

    concurrency instance-attribute ¶

    concurrency = concurrency

    http instance-attribute ¶

    http: Client = build_client(base_url=self.base_url, auth=auth, timeout=timeout, rate_limit=rate_limit, log_http=log_http, transport=transport, verify=verify, proxy=proxy)

    The underlying httpx2.Client: auth, base URL, retries and logging are already set. Use it for routes missing from the published spec.

    credential_kind property ¶

    "secret_key", "jwt" or None.

    spec property ¶

    The endpoint registry, loaded the first time it is needed.

    secret_keys property ¶

    List, create, rotate and delete secret keys (SecretKeys).

    tag_lists property ¶

    tag_lists: TagLists

    Create, fill and resolve tag lists (TagLists).

    secret_key property ¶

    secret_key: str | None

    The secret key in use, if the credential is one.

    close ¶

    close() -> None

    Close the connection pool. The client can't be used afterwards.

    refresh_spec ¶

    refresh_spec() -> Registry

    Fetch the live spec now, replacing the copy in use.

    request ¶

    request(method: str, endpoint: str, *, license: Any = None, params: Mapping[str, Any] | None = None, json: Any = None, files: Any = None, data: Any = None, submit: bool | None = None, timeout: float | None = None, **path_params: Any) -> Any

    Call any endpoint in the spec.

    endpoint is an endpoint ID (METRC_ACTIVE_ITEMS) or a path (/v2/items or /v2/items/{object_id}). Path parameters are keyword arguments. license fills licenseNumber; it defaults to the client's license when the endpoint requires one.

    Returns parsed JSON, bytes for other content, or None for an empty body.

    collect ¶

    collect(endpoint: str, *, license: LicenseArg = None, filter: str | Sequence[str] | None = None, filter_logic: Literal['and', 'or'] | None = None, sort: str | None = None, mask: str | Sequence[str] | None = None, page_size: int | None = 100, progress: bool | None = None, params: Mapping[str, Any] | None = None, **path_params: Any) -> list[dict[str, Any]]

    Load every page of a collection, in parallel, as one list.

    Parameters:

    Name Type Description Default
    endpoint str

    A collection's endpoint ID or path.

    		 required
    license LicenseArg

    One license, or a list to load one after another. Defaults to the client's license.

    		 None
    filter str | Sequence[str] | None

    field__op:value filters (one string or a list).

    		 None
    filter_logic Literal['and', 'or'] | None

    "and" (default on the server) or "or".

    		 None
    sort str | None

    field:asc or field:desc.

    		 None
    mask str | Sequence[str] | None

    Fields to return (collectionMask).

    		 None
    page_size int | None

    Rows per page.

    		 100
    progress bool | None

    Show a progress bar. Defaults to on when stderr is a terminal.

    		 None
    params Mapping[str, Any] | None

    Any other query parameters, by their spec names.

    		 None

    A page that still fails after retries fails the whole call.
