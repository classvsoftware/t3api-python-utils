    Spec¶

    client.spec is a Registry built from one copy of the T3 OpenAPI spec. See endpoints and the spec.

    Registry ¶

    Registry(spec: Mapping[str, Any], source: SpecSource | None = None)

    Every operation in one copy of the spec.

    version property ¶

    version: str

    source instance-attribute ¶

    source = source

    endpoints instance-attribute ¶

    endpoints: list[Endpoint] = self._build()

    list ¶

    list(kind: Kind | None = None) -> builtins.list[Endpoint]

    Every endpoint, or every endpoint of one kind.

    find ¶

    find(query: str = '', kind: Kind | None = None) -> builtins.list[Endpoint]

    Endpoints whose ID, path, summary or tags contain every word of query.

    endpoint ¶

    endpoint(name: str, *, method: str | None = None, kind: Kind | Iterable[Kind] | None = None, path_params: Iterable[str] | None = None) -> Endpoint

    Find one operation by endpoint ID or path.

    One ID or path can name several operations. method, kind and the names of the path parameters you have narrow it down to one.

    ids ¶

    ids() -> builtins.list[str]

    check_params ¶

    check_params(endpoint: Endpoint, query: Mapping[str, Any], path_values: Mapping[str, Any], *, has_body: bool, python_names: Mapping[str, str] | None = None) -> None

    Raise SpecError for missing required parameters, warn about unknown ones.
